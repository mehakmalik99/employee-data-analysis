# Employee Data Analysis

## Project Overview

This project focuses on cleaning, exploring, and visualizing employee data using Python. The analysis includes handling missing values, identifying duplicates and unusual values, performing exploratory data analysis, and creating visualizations to understand employee-related patterns.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Plotly
- Jupyter Notebook

## Dataset

The dataset contains employee information including:

- Employee ID
- Name
- Age
- Salary
- Department
- Join Date
- City
- Performance Score
- Email

## Data Cleaning

The project includes:

- Identifying and handling missing values
- Filling missing Salary and Performance Score values
- Handling missing City and Email values
- Removing records with missing Join Date
- Checking for duplicate records
- Identifying unusual values and potential outliers

## Exploratory Data Analysis

The analysis explores employee data to understand patterns and relationships across different attributes such as:

- Age
- Salary
- Department
- City
- Performance Score
- Joining Date

## Data Visualization

Visualizations were created to make the analysis easier to understand and identify important patterns in the data.

## Project Files

- `ANALYZE_DATA.ipynb` — Jupyter Notebook containing the complete analysis
- `messy_employee_data.csv` — Dataset used for the analysis

## Objective

The objective of this project is to practice the complete data analysis workflow, from raw and messy data to cleaned data, exploratory analysis, and visual insights.
